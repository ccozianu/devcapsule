# Intake: `component-upgrades`

Pending work delivered to this workstream. Senders use the coordination branch:

```text
devcapsule workflow mail send component-upgrades <file>
```

Name each item `YYYY-MM-DD-<sender-mnemonic>-<slug>.md`. Never deliver through
main or by editing this directory. The recipient takes mail, commits it, then
records each decision and removes the item according to `WORKFLOW.md`.
Bug ownership belongs in bug frontmatter, not in an intake item.
