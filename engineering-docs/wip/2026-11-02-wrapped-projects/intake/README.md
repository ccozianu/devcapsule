# Intake: `wrapped-projects`

Work other workstreams have delivered to `wrapped-projects` and that it has not
yet decided. Senders add one file per item, named
`YYYY-MM-DD-<sender-mnemonic>-<slug>.md`, and deliver it by mail on the
coordination branch, never through `main` or by editing this directory. Each
item is acknowledged into the status file or forwarded as `WORKFLOW.md`
permits, and every decision is recorded in `intake-dispositions.md` before the
item is removed.
