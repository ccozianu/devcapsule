# Intake: `capsule-webconsole`

Work other workstreams have delivered to `capsule-webconsole` and that
`capsule-webconsole` has not yet decided.

Senders add one file per item, named `YYYY-MM-DD-<sender-name>-<slug>.md`,
and deliver it by mail on the coordination branch. Senders never remove or
reclassify items, and never edit anything else in this workstream's
directory.

`capsule-webconsole` decides each item, records the outcome in its decision
log, then removes the file. This is a queue, not an archive; Git retains the
history. A file still present here has not been decided.
