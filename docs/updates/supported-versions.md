# Supported versions

Every released version has its own copy of this
[documentation](../README.md), at its own address. The version switcher at the
top of each page moves between published documentation sets and opens the
versions index (*all versions*), which lists every released version and its
status. Each version's documentation describes that release and only that
release.

DevCapsule 0.x is for early adopters. The project publishes documentation for
every release and asks you to run the current release, which is the one that
receives fixes. Patching a release older than two weeks is at the project's
discretion. A support policy with defined maintenance windows comes with V1.

Upgrading the launcher is a single download using the same steps as
[Install DevCapsule](../getting-started/install.md); your projects' locks,
your checkout records, and your [configuration home](../configuration/home.md)
stay as they are. See [Launcher updates](launcher-updates.md),
[Component freshness](component-freshness.md), and
[Component upgrades](component-upgrades.md) for how update checks work and how
to test or roll back component versions.
