# Supported versions

Every released version has its own copy of this documentation, at its own
address; the switcher at the top of each page moves between them, and the
[versions index](../README.md) lists them with their status. The
documentation of a version describes that version, and only that version.

DevCapsule 0.x is for early adopters. The project publishes the
documentation of every released version and asks you to run the current
release: it is the one that gets fixes. Whether a release older than two
weeks is patched is at the project's discretion. A support policy with
defined windows comes with V1.

Upgrading the launcher is one download, the same steps as
[Install](../getting-started/install.md); your projects' locks and your
recorded choices stay as they are. What an update check tells you, and how
to try a newer component and roll back, are on
[Launcher updates](launcher-updates.md), [Component freshness](component-freshness.md)
and [Component upgrades](component-upgrades.md).
